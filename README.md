# カウントソフト<br>
3つの対象をカウントしていけます。

痛風発病記念に２リットルの水をも接種するために作成しました。<br>
アイコンはフリーサイトのものを使ってます。

実行ファイルReleaseにv145でビルドしたx86版が入ってます。<br>
<br>
・DrinkCount.exe<br>
・Data<br>
　　　・Log.ini       （カウントの記録）       <br>
　　　・Screen.ini    （起動時の画面位置 [オプション]）<br>
　　　・Settingf.ini  （ボタンの名前 [オプション]）<br>
